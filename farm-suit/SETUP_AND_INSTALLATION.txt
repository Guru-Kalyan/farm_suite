3. DATABASE SETUP (POSTGRESQL)
================================================================================
1. Open your terminal, command prompt, or pgAdmin:
   psql -U postgres

2. Create the dedicated database for Farm Suit:
   CREATE DATABASE farm_suit_db;

3. (Optional) Create a dedicated user if not using the default postgres superuser:
   CREATE USER farm_admin WITH PASSWORD 'secure_password';
   GRANT ALL PRIVILEGES ON DATABASE farm_suit_db TO farm_admin;

4. Verify database creation:
   \l
   Exit psql:
   \q

4. BACKEND SETUP & CONFIGURATION (DJANGO)
================================================================================
1. Navigate to the backend directory:
   cd farm-suit/backend

2. Create and configure the environment file:
   Ensure a file named `.env` exists in `farm-suit/backend/` with the following:

   -----------------------------------------------------------------------------
   SECRET_KEY=django-insecure-farm-suit-production-key-change-in-prod-2026
   DEBUG=True
   ALLOWED_HOSTS=*
   DATABASE_NAME=farm_suit_db
   DATABASE_USER=postgres
   DATABASE_PASSWORD=root
   DATABASE_HOST=127.0.0.1
   DATABASE_PORT=5432
   -----------------------------------------------------------------------------
   * Adjust DATABASE_USER and DATABASE_PASSWORD to match your PostgreSQL setup.

3. (Recommended) Create and activate a Python virtual environment:
   Windows:
     py -m venv venv
     .\venv\Scripts\activate

   Linux / macOS:
     python3 -m venv venv
     source venv/bin/activate

4. Install the required Python dependencies:
   pip install -r requirements.txt

5. Apply database migrations:
   python manage.py migrate
   (On Windows without venv: py manage.py migrate)

6. Create an administrator account (if not already created):
   python manage.py createsuperuser
   - Username: admin
   - Email:    admin@farmsuit.local
   - Password: admin123 (or your preferred password)

5. FRONTEND SETUP & CONFIGURATION (REACT + VITE)
================================================================================
1. Open a new terminal window and navigate to the frontend directory:
   cd farm-suit/frontend

2. Install all Node.js / npm dependencies:
   npm install

3. Verify the Vite configuration:
   The `vite.config.js` file is pre-configured with:
   - `host: '0.0.0.0'` (Allows local network and mobile access)
   - `port: 5173`
   - Proxy: `/api` -> `http://127.0.0.1:8000` (Seamless backend forwarding)

7. MOBILE NETWORK ACCESS SETUP
================================================================================
To access Farm Suit from a mobile phone or tablet on the same Wi-Fi network:

1. Discover your computer's local IP address:
   Windows: Run `ipconfig` in Command Prompt (look for IPv4 under Wi-Fi, e.g. 192.168.29.100)
   Linux:   Run `ip addr` or `hostname -I`
   macOS:   Run `ipconfig getifaddr en0`

2. Connect your mobile device:
   Connect your mobile phone to the EXACT SAME Wi-Fi network as the computer.

3. Open the Mobile Browser:
   Navigate to:
   http://<YOUR_COMPUTER_IP>:5173/
   (Example: http://192.168.29.100:5173/)

4. Sign In:
   Enter username `admin` and password `admin123`.

* Note: The responsive interface will automatically adapt with a mobile slide-out drawer (☰) and touch-friendly controls.

10. TROUBLESHOOTING & COMMON FIXES
================================================================================

ISSUE 1: "FATAL: password authentication failed for user 'postgres'"
--------------------------------------------------------------------------------
Fix: Open `farm-suit/backend/.env` and update `DATABASE_PASSWORD` to match the
password you set when installing PostgreSQL.

ISSUE 2: "Port 5173 is already in use"
--------------------------------------------------------------------------------
Fix on Windows:
  netstat -ano | findstr :5173
  taskkill /F /PID <process_id>
Fix on Linux / macOS:
  lsof -i :5173
  kill -9 <process_id>

ISSUE 3: "Mobile phone cannot connect / Connection timed out"
--------------------------------------------------------------------------------
Checklist:
1. Ensure both devices are on the SAME Wi-Fi network (not a guest network with AP isolation).
2. On Windows: Open Settings -> Network & Internet -> Wi-Fi -> Properties -> Ensure Network profile is set to "Private".
3. Check Windows Defender Firewall: Ensure Node.js and Python are permitted through the firewall.

ISSUE 4: "CSRF verification failed" on mobile device
--------------------------------------------------------------------------------
Fix: In `farm-suit/backend/config/settings.py`, the system is configured to
automatically detect and whitelist local network IP addresses dynamically.
If using a custom domain or reverse proxy, add your domain to `CSRF_TRUSTED_ORIGINS`
in `settings.py`.

ISSUE 5: "Building the Frontend for Production"
--------------------------------------------------------------------------------
To compile a static production bundle:
cd farm-suit/frontend
npm run build
The output will be placed in `farm-suit/frontend/dist/` ready to be served via
Nginx, Caddy, or Django static files.
